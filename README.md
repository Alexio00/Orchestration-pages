# Orchestration Pages

Публичные, версионированные инструкции по активации General 5.

Сайт публикуется GitHub Actions из этого репозитория. Канонические тексты General и адаптеров находятся в приватном `Alexio00/Orchestration` и передаются сюда только через контролируемый workflow публикации.

## Публичный состав

- `index.html`, `styles.css`, `app.js` — статический интерфейс;
- `content/latest/` — актуальные опубликованные инструкции;
- `content/releases/<tag>/` — неизменяемые снимки версий;
- `.github/workflows/pages.yml` — публикация GitHub Pages.

Приватные документы разработки, состояние проектов и секреты сюда не передаются.
