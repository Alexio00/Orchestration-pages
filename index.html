General 5 — инструкция по активации

General 5.0.0 · Bootstrap 1.1.1 · Cloud Adapter 1.1.1

General 5 — PM-оркестратор для ведения проектов. Выберите один способ активации в зависимости от среды.

1. Первое сообщение в чате

Используйте этот вариант для отдельного чата без постоянных инструкций проекта.

Шаг 1. Создайте новый чат.

Шаг 2. Скопируйте блок целиком и отправьте его первым сообщением.

Шаг 3. Следующим сообщением передайте состояние проекта или обычную задачу.

Загрузка…

Правила действуют только в текущем чате. В новом чате активацию нужно повторить.

2. Инструкции проекта

Используйте этот вариант для постоянной работы в ChatGPT Project или Claude Project.

Шаг 1. Откройте инструкции проекта.

Шаг 2. Замените прежнюю версию General полным блоком ниже.

Шаг 3. Добавьте PROJECT-STATE.md в файлы или знания проекта.

Загрузка…

Не наслаивайте несколько версий General. После сохранения начните новый чат с обычной задачи.

3. Setup script для Claude Code cloud

Используйте этот вариант для облачного окружения Claude Code.

Шаг 1. Откройте настройки окружения на claude.ai/code.

Шаг 2. Скопируйте весь блок в поле Setup script.

Шаг 3. Сохраните окружение и запустите новую cloud-сессию.

Загрузка…

Скрипт обновляет только управляемый блок глобального CLAUDE.md и сохраняет остальное содержимое.
