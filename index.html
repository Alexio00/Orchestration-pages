Для чата без проекта

Отправьте промпт первым сообщением

  1. Создайте новый чат.
  2. Скопируйте блок целиком и отправьте первым сообщением.
  3. Следующим сообщением передайте состояние проекта или обычную задачу.

Правила действуют только в текущем чате. Новому чату потребуется повторная активация.

Для постоянной работы в проекте

Добавьте полный адаптер в инструкции проекта

  1. Откройте инструкции ChatGPT Project или Claude Project.
  2. Замените прежнюю версию General полным блоком ниже.
  3. Добавьте PROJECT-STATE.md в файлы или знания проекта.

Не наслаивайте несколько версий General. После сохранения начинайте новый чат с обычной задачи.

Для облачного окружения Claude Code

Вставьте скрипт в настройки окружения

  1. Откройте настройки окружения на claude.ai/code.
  2. Скопируйте весь блок в поле Setup script.
  3. Сохраните окружение и запустите новую cloud-сессию.

Скрипт обновляет только управляемый блок глобального CLAUDE.md и сохраняет остальное содержимое.
